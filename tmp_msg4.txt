refactor(studio): rename sidebar_layout to shell

The design idiom's founding discussion has Sandi Metz naming this leak on
its first page: "A 'sidebar' is not substance; it is a physical coordinate
on a horizontal desktop monitor. What that component actually represents is
a catalog, an index, or a document_manifest." The substance templates were
renamed to `catalog` at the time; the wrapper they were drawn inside kept
the spatial name, and it was authored in six .sp files — the exact
presentation-in-substance leak the discussion was convened to remove.

The word is now `shell`, which is what the codebase already called it: the
compiler's `KIND_WRAPPERS` maps `kind: shell`, and workbench.design declares
`surface workbench, kind: shell`. Its partial is unchanged — `box` with
children, no spatial term in it — so only the name and the class it promotes
move. `--sidebar-width` becomes `--shelf-width`, the width of the shell's
first column, which the workbench calls the shelf.

Left alone deliberately, as a different thing wearing a similar word: the
studio chrome's own navigation (a real sidebar, in app code rather than in
an authored word), the test fixtures that use `sidebar` as a domain name,
and taxonomy's `:sidebar` structural primitive, whose role reads "one
element has intrinsic width and the other fills remaining space" — a fact
about the layout, not about a screen position.

Verified live on every page type: each renders `class="box shell"` and no
page emits the old name. DESIGN_IDIOM.md's horizon example was regenerated
from the compiler, which the design-docs checker demanded.
